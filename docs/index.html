✔ 7-Axis Pre-Emit Quality Gate

Axis Requirement Failure Condition
1. Memory Boundness Stream in 4MB chunks, peak RAM ≤ 8MB Attempting full in-memory JSON load
2. Boundary Overlap 4KB sliding window; match counted only if end > overlap Truncating split phrases across chunk boundaries
3. Verbatim Quotes 100% exact substring matches with ISO dates Synthesizing or paraphrasing user quotes
4. Multiplicity Ratio Rank by $U \times \sqrt{H}$, prioritize $U \ge 3$ chats Elevating 1 user's spam to #1 market need
5. Service Filtering Filter type: service and bot commands Counting join/leave events as pain points
6. Honesty Guarantee Unverified uniqueness labeled "I cannot confirm this" Hallucinating competitor absence
7. Zero Network Exfiltration 100% local, air-gapped offline analysis Sending chat history over external API calls
