ChatExport Need Miner

Mine offline Telegram Desktop chat exports for unmet needs, product opportunities, and repeated complaints with quote-grounded evidence.

npx skills add wwewtech/chatexport-need-miner

Core Features

Chunked Streaming Pipeline

Process 100MB-1GB+ result.json files seamlessly. The skill reads 4MB chunks with overlap tails instead of loading the entire file, preventing context length limits and memory crashes.

Need Lexicon

Detects precise intent using English ("i wish", "missing") and Russian ("не хватает", "бесит") heuristics rather than generic LLM summaries, surfacing actionable product gaps.

Quote Grounding

Every identified theme must carry 2-5 verbatim quotes with dates. Never hallucinates complaints; labels unverified themes as unsupported.

Offline & Private

No API keys, bots, or MTProto. Operates strictly on local JSON dumps, preserving user privacy for sensitive community exports.

Output Contract

The skill enforces a strict, verifiable output format grouping raw evidence into actionable opportunities.
